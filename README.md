# cmsc408-sp2025-hw8

## Overview

Using a structured SQL database with data from the World Bank, this analysis focuses on:

- Country and region metadata
- Income classifications
- Data cleaning and table creation
- Aggregation by region and income level
- Anomaly detection and correction
- Pivot-style summaries and percentages

## Features

- Robust use of `SELECT`, `GROUP BY`, `ORDER BY`, and `CASE` statements
- CTEs and subqueries for advanced analysis
- Manual data correction using `UPDATE`
- Regional/income pair summaries and visualizations
- Percentage breakdowns and cross-tabulation analysis

## Technologies

- SQL
- Python (via Quarto and Jupyter-like markdown cells)
- Helper functions for SQL execution (from provided `helpers.py`)

## Example Output

- Total countries in each region
- Distribution of income groups
- Percentage of global countries per income level
- Regions missing specific income groups
- Corrected misclassified country records

## Learning Outcomes

- Improved fluency in SQL syntax
- Better understanding of data cleaning and transformation
- Comfort with grouping, joins, and CTEs
- Real-world exposure to relational data analysis
